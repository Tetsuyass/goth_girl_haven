# Goth Girl Haven
Mon site web Rent A Goth


🎨 Rapport de Design – Rent A Goth
💀 Pourquoi ce design ?
Le thème du site s’inscrit dans une esthétique gothique assumée, à la fois sombre, élégante et moderne.
Nous avons choisi :

Palette de couleurs : dominante de noir, gris foncé, violet sombre, avec des touches d’or pour faire ressortir les éléments importants comme les liens ou boutons.

Typographies : un mélange entre Cinzel, Baskerville Old Face et UnifrakturCook, pour évoquer une ambiance néo-victorienne, mystique et raffinée.

Mise en page : usage de Flexbox et CSS Grid selon les besoins : Flexbox pour la navigation, les blocs de blog et profils ; Grid pour la page de contact. Cela permet une mise en page responsive, claire et structurée.

⚙️ Fonctionnalités et effets utilisés
🌐 Structure
Organisation en pages modulaires : Accueil, Blog, FAQ, Contact, Profils, Inscription.

Usage de partials SCSS pour un code propre et réutilisable (_variables.scss, _responsive.scss...).

✨ Interactions et animations
Slider d’images avec navigation manuelle (JS) pour la mise en avant de figures gothiques.

Effets au survol des liens : animation fluide avec ::after, transitions de couleur sur les menus.

Navigation stylée avec hover et highlight dynamique pour renforcer l’expérience visuelle.

Formulaire dynamique (Inscription + Contact) : bien structuré, avec placeholder et état focus personnalisé.

📱 Responsive design
Fichier _responsive.scss conçu pour adapter le site à tous les formats (mobile, tablette, desktop).

Breakpoints bien pensés, adaptés à la navigation tactile, avec réorganisation automatique des blocs.

Ce projet mélange ambiance gothique et web design moderne pour offrir une expérience utilisateur unique et cohérente, en rendant hommage à une esthétique forte tout en garantissant accessibilité et fluidité.
